# BreakFree

A student-built React/Vite project created for Anvesh Bharat. BreakFree is designed to make drug-awareness and recovery information easier to understand and help people find trustworthy support.

## Features
- Responsive dark UI with the BreakFree brand logo and visual system
- English / Hindi language toggle
- Personal Plan questionnaire with a personalised support plan
- Next Step interactive support flow
- Local streak and milestone tracker with interactive reward reveals
- Daily check-in reflection cards
- FAQ, Help & Support, Crisis Help and Contact pages
- Bibliography with project sources
- About Us page linked only from the footer

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.
