# BreakFree School Project

A React + Vite school project about drug awareness, recovery support and finding help.

## Run it

Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Then open the local address Vite gives you (usually http://localhost:5173/).

## Pages

- Home
- Next Step — interactive support picker
- FAQ
- Help & Support
- Streak & Rewards — local progress tracker + milestone badges
- Contact
- Directions
- Crisis Help
- Bibliography

## Bibliography

The Bibliography page lists the websites used to check the factual and helpline information in the project. The recovery stories are example stories written for the project, and the website's design/features are original project work.

Helpline details can change. For current information, use the official source listed on the Bibliography page.
